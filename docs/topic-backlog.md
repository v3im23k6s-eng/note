# テーマバックログ

依頼文に挙がっていたテーマを記事カテゴリごとに整理したリストです。
新しい記事を書くときはここから選ぶか、なければ追加してください。

**このリストは固定ではありません。** 就活に関することであれば、ここに載っていないテーマや、
まだ広く使われていない新しい言葉・概念でも扱ってよいです。特に就活の最新ニュースは執筆のたびに
確認し、動きがあれば新規テーマとしてこの表に追記してください（文体ルール自体は変えません）。

ステータス: `未着手` / `執筆中` / `初稿済み` / `公開済み`

`初稿済み` はこのリポジトリ内で原稿が完成した状態、`公開済み` は実際にnoteに投稿が完了した状態を指します。
投稿はこのリポジトリの外（Chrome版Claudeでnoteの編集画面に入力する作業）で行うため、実際に公開したら都度このステータスを更新してください。
