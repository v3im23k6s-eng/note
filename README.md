# note

「フルトレ就活」のnote記事を管理・執筆するためのリポジトリです。

日経大手四社から内定を得た経験と、デザイン思考テストで高得点を獲得した経験をベースに、
大学3・4年生の就職活動者向けに、実体験ベースの就活支援コンテンツを書いていきます。

## 扱うテーマ

- 就活の最新ニュース・スケジュール
- 思考法（ロジカルシンキング、クリティカルシンキング、ラテラルシンキング、仮説思考、システム思考、ゼロベース思考）
- 分析フレームワーク（MECE、ロジックツリー、意思決定ツリー、PREP法、PDCAサイクル、フェルミ推定、市場規模推計）
- デザイン思考テスト、ウェブテスト対策
- 面接対策（ケース面接、STAR面接法、コンピテンシー面接、構造化面接）
- 自己分析・ガクチカ作成・Will-Can-Must・キャリアアンカー
- 社会人基礎力・ポータブルスキル・ファシリテーション・アサーティブコミュニケーション・ネゴシエーション
- DX・生成AI・データリテラシー
- ジョブ型雇用・メンバーシップ型雇用

すべてのテーマは `docs/topic-backlog.md` で管理しています。

## 構成

- `CLAUDE.md` — 記事執筆時の運用ルール（最初に読むファイル）
- `docs/style-guide.md` — 文体ルール（本文を書く前に必ず確認）
- `docs/feedback-log.md` — フィードバックの記録
- `docs/topic-backlog.md` — 記事テーマのバックログ
- `docs/original-request.md` — 最初の依頼文（背景情報）
- `articles/` — カテゴリ別の記事本体

## 使い方

新しい記事を書くときは、まず `CLAUDE.md` の「記事を書く前に必ずやること」に沿って進めてください。
