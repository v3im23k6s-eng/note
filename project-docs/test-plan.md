## 今後の観点(機能追加時に追加すべきテスト)

- 認証失敗・通信エラー・APIエラー・レート制限: 本ツールはAPI通信を行わないため対象外
  (将来X公式APIでの投稿を追加する場合は、この節を拡張する)
- 文字数や入力形式の不正: `targetLen`の全角数字入力・範囲外入力のクランプ処理
- 同一内容の重複: 上記#8で確認済み
- プロセス再起動後の二重投稿: 本ツールは投稿を代行しないため、二重投稿はXアプリ側の操作に依存する
- ログに秘密情報が残らないこと: 秘密情報自体を扱わないため該当なし
