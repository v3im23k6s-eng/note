# 運用方法

## 初回セットアップ(利用者に行っていただく作業)

1. **GitHub Pagesを有効化する**(このリポジトリの設定画面で1回だけ)
   1. GitHubでこのリポジトリを開く
   2. 「Settings」タブ → 左メニューの「Pages」
   3. 「Build and deployment」の「Source」を **Deploy from a branch** にする
   4. Branch を **main**、フォルダを **/docs** にして「Save」
   5. 数分待つと、`https://<ユーザー名>.github.io/<リポジトリ名>/` のようなURLが発行される
2. スマホでそのURLを開き、ブラウザの「共有」→「ホーム画面に追加」を行う
3. 以後は必ずこのホーム画面アイコンから開く(同じブラウザアプリを使い続けることで
   設定・履歴が正しく保持される)

## 日々の使い方

1. ホーム画面のアイコンから開く
2. (初回のみ)左上「トレーニング設定」を開き、ペルソナ・note誘導リンク・鉄板テーマなどを
   自分の言葉に調整して「設定を保存」
3. 「今日のセット」→ STEP1「指示文を作る」→「指示文をコピー」
4. 「Claudeを新しいタブで開く」→ 新しいチャットに貼り付けて送信
   (Web検索がオンになっているか確認すると、最新情報を踏まえた投稿になる)
5. Claudeの回答をコピーし、ツールに戻ってSTEP2の貼り付け欄にペースト →「解析してカード表示」
6. カードを見て、気に入ったものの「コピー」または「Xで下書きを開く」を押す
7. Xに投稿したら、そのカードの「使用済みにする」を押す(次回以降の重複防止に使われる)
8. 引用RTコメントが欲しい場合は、下の「引用リツイート コメント」セクションで同様の手順

## 定期メンテナンス(任意・週1回程度)

- 「鉄板テーマ・切り口」欄を最近の話題に更新する
- 「誘導したいnote記事」を最新のものに更新する
- 「トレーニング履歴」で古い履歴を整理する(削除しても直近の重複防止には影響しない範囲で)

## 停止方法

ページを閉じるだけ。バックグラウンドで動く処理は存在しない。

## トラブル時

- 設定や履歴が消えたように見える場合 → ホーム画面アイコン以外(別のブラウザアプリ等)から
  開いていないか確認する
- 「バックアップ/復元」パネルで定期的に「エクスポート」した内容をメモアプリ等に控えておくと、
  万一データが消えても復元できる
